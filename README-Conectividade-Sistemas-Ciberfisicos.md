# Projetos de Conectividade de Sistemas Ciberfísicos

Este repositório reúne **dois projetos independentes** sobre comunicação e redes. O projeto em Python não faz parte da simulação no Cisco Packet Tracer.

## Projetos

| Projeto | Descrição |
| --- | --- |
| `Proj_2_UDP_Multicast/` | Projeto em Python sobre comunicação UDP multicast, com `servidor.py`, `cliente.py`, README próprio e relatório. |
| `Projeto fechado.pkt` | Simulação no Cisco Packet Tracer de uma rede que interliga a empresa e sua filial. |

## Como abrir

- **UDP multicast:** acesse a pasta `Proj_2_UDP_Multicast/` e consulte o `README.MD` dela para executar o cliente e o servidor em Python.
- **Rede empresa–filial:** abra `Projeto fechado.pkt` no Cisco Packet Tracer para explorar a topologia e testar a comunicação na simulação.
